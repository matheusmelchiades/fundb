Five databases. One engine.

Every data type your AI agents need, unified in a single cognitive engine with native confidence tracking, causal reasoning, and context-aware retrieval.

Vectors

HNSW approximate nearest neighbor search with adaptive recall and product quantization. Sub-5ms p99 on 10M vectors.

Graphs

SPO triple store with multi-hop traversal, causal DAG indexing, and native path queries. Traverse 1M edges in under 10ms.

Documents

Flexible JSON documents with schema-on-read. Every record carries confidence scores, provenance chains, and causal metadata.

Time-Series

Bitemporal MVCC with system time and valid time. Time-travel queries, temporal range scans, and Granger causality built in.

Agent Memory

REMEMBER, RECALL, and FORGET primitives with semantic decay. Give your AI agents persistent, searchable long-term memory.

SQL for the AI era

FunQL extends PostgreSQL with native primitives for vectors, graphs, causal reasoning, context-aware retrieval, and agent memory. Connect with psql and start querying.

funql 
-- Context-aware retrieval optimized for LLM token budgets
SELECT title, abstract, _confidence, _sources
FROM research_papers
WHERE _vector('content_embedding') <-> :query < 0.5
  AND _confidence > 0.7
WITHIN CONTEXT (
  max_tokens: 4000,
  coherence: 0.8,
  diversity: 0.3
);
-- Trace what caused the error spike
TRACE CAUSALITY
FROM deployment_event TO error_spike
MAX_DEPTH 5
MIN_STRENGTH 0.6;

-- Counterfactual: what if we had spent more?
ESTIMATE COUNTERFACTUAL
  GIVEN revenue = 100000, marketing_spend = 30000
  HAD marketing_spend = 50000
  PREDICT revenue;
-- Give your AI agent persistent memory
REMEMBER agent_id='agent-007'
  CONTENT 'User prefers concise answers with code examples'
  IMPORTANCE 0.8;

-- Recall with semantic search + decay
RECALL BY agent_id='agent-007'
  QUERY 'user preferences'
  TOP_K 5;

Up and running in 60 seconds

FunDB speaks PostgreSQL wire protocol. Your existing tools already work.

1

Start FunDB

terminal 
# Docker (recommended)
docker compose up -d
2

Connect

terminal 
psql -h localhost -p 5433 -U fundb
3

Query

funql 
UNDERSTAND 'find recent papers
  about transformers with
  high confidence';
